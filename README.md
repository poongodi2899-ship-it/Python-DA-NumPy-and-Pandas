# Python-DA-NumPy-and-Pandas
## 📖 Project Summary

This project is a **Python Data Analytics Assignment** that focuses on building a strong foundation in **NumPy** and **Pandas**, two of the most essential libraries for data analysis in Python. The assignment demonstrates how to perform numerical computations, manipulate structured datasets, and extract meaningful insights using real-world scenarios.

### 🎯 Project Objectives

* 📌 Create and manipulate **1D and 2D NumPy arrays**
* 🌡️ Analyze weekly temperature datasets using numerical operations
* 🔍 Perform array indexing, slicing, and statistical calculations
* 📊 Create and manage **Pandas Series** with custom labels
* 🗂️ Build and explore **Pandas DataFrames**
* 🔎 Apply filtering, grouping, and aggregation techniques
* ✏️ Update, add, and remove data efficiently
* 💡 Develop practical data analysis skills through structured Python programming

### 🚀 Key Features

* ✅ NumPy Array Creation and Inspection
* 🌡️ Celsius to Fahrenheit Conversion
* 📈 Statistical Analysis (Maximum, Minimum & Mean)
* ✂️ Array Indexing and Slicing
* 📋 Pandas Series Operations
* 📊 DataFrame Creation and Exploration
* 🔍 Conditional Data Filtering
* 📌 GroupBy Analysis and Aggregation
* ✏️ DataFrame Modification (Update, Add & Delete Columns/Rows)
* 💻 Clean, organized, and beginner-friendly Python code

### 🛠️ Technologies Used

* 🐍 Python
* 🔢 NumPy
* 🐼 Pandas
* 📓 Google Colab / Jupyter Notebook

### 📚 Learning Outcomes

Through this assignment, I gained hands-on experience in working with NumPy arrays and Pandas data structures for real-world data analysis. I learned how to inspect datasets, perform numerical computations, manipulate structured data, apply filtering and aggregation techniques, and organize data efficiently using Python. This project strengthened my understanding of core Data Analytics concepts and improved my practical coding skills for future data-driven projects.
