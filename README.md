# Python-DA-NumPy-and-Pandas
# 🐍 Python DA Assignment 1 – NumPy and Pandas

## 📖 Project Overview

This project is a Python Data Analytics Assignment that demonstrates the practical application of **NumPy** and **Pandas** for performing numerical computations, structured data manipulation, and exploratory data analysis. The assignment is designed to strengthen fundamental Python programming skills while working with real-world datasets such as temperature records and transaction data. Throughout this project, various analytical techniques are implemented to understand data structures, perform calculations, manipulate datasets, and generate meaningful insights.
